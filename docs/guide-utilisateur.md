# Twins · Guide utilisateur

Twins, c'est l'abonnement **« 1 acheté = 1 offert »** chez les restaurants, cafés, instituts et
commerces de votre quartier. Le site s'utilise dans le navigateur, sur téléphone comme sur ordinateur :
**https://projet-duo-delta.vercel.app**

En bas de l'écran sur téléphone, en haut sur ordinateur, la navigation donne accès à tout : **Accueil**, **Offres**,
**Économies** et **Compte**.

---

## Vous êtes membre

### Créer votre compte
1. Touchez **Compte**, puis **Créer un compte**.
2. Choisissez **Je suis membre**, puis indiquez votre prénom, votre e-mail et un mot de passe
   de 6 caractères au moins.
3. Touchez **Créer mon compte** : vous arrivez dans votre espace membre.

Déjà inscrit ? Touchez **Compte** puis **Se connecter**. Vous restez connecté même si vous
fermez la page. Pour sortir, touchez **Se déconnecter**.

### Vous abonner
1. Dans votre espace, touchez **Je m'abonne** (le même bouton se trouve dans la rubrique
   « Ton abonnement » de la page d'accueil).
2. Vérifiez le prix et ce que comprend l'abonnement, puis touchez **Activer mon abonnement**
   et **Confirmer**. Le paiement est simulé : rien ne vous est demandé.
3. Votre espace affiche **Abonné jusqu'au …** : l'abonnement dure 12 mois.

### Trouver une offre
1. Touchez **Offres** : toutes les offres s'affichent, celles **valables aujourd'hui** en premier.
2. Filtrez par catégorie en touchant une pastille (Restaurant, Café et boulangerie, Beauté et
   bien-être, Loisirs, Commerce).
3. Touchez **Plus de filtres** puis **Valables aujourd'hui seulement** pour ne garder que les
   offres utilisables tout de suite. Les deux filtres se combinent.
4. Chaque carte indique le commerce, la ville, l'offre, ses jours et la valeur de l'article
   offert. Une offre qui n'est pas valable aujourd'hui affiche son prochain jour (« Dès samedi »).

Aucun résultat ? Touchez **Retirer les filtres**.

### Utiliser une offre en caisse
1. Touchez la carte de l'offre : vous voyez la fiche du commerce, les conditions, les jours de
   validité, la valeur de l'article offert et le nombre d'utilisations qu'il vous reste.
2. En caisse, touchez **Utiliser**. Deux façons de valider :
   - **Code du commerçant** : tendez votre téléphone, le commerçant tape son code à 4 chiffres ;
   - **QR code** : montrez le QR code, le commerçant le scanne avec son téléphone (ou tape le
     code court de 6 caractères affiché dessous). Le QR code vaut 5 minutes, une seule fois.
3. L'écran affiche **Offre validée**, avec le **numéro de validation**, l'heure et l'économie,
   en grand pour que le commerçant le voie. Le deuxième article vous est offert.

Si **Utiliser** est grisé, une phrase en dessous dit pourquoi :

| Message | Ce que ça veut dire |
|---|---|
| Abonnez-vous pour utiliser cette offre | Vous n'avez pas d'abonnement en cours |
| Pas valable aujourd'hui : revenez … | L'offre ne vaut que certains jours |
| Vous avez déjà utilisé cette offre autant de fois que permis | La limite fixée par le commerçant est atteinte |

### Suivre vos économies
Touchez **Économies** : le total économisé depuis le début de votre abonnement, le nombre
d'offres utilisées et l'historique (date, commerce, offre, économie, numéro de validation),
le plus récent en premier. Le total se met à jour dès qu'une offre est validée.

## Vous êtes commerçant

### Créer votre compte et votre fiche
1. Touchez **Compte**, **Créer un compte**, puis choisissez **Je suis commerçant**.
2. Avant tout le reste, Twins vous demande de **créer votre fiche** : nom, catégorie, adresse,
   ville, description (300 caractères au plus) et, si vous le souhaitez, une **photo** de votre
   commerce : **Depuis mon appareil** (une photo de votre ordinateur ou de votre téléphone,
   réduite automatiquement) ou **Coller un lien** vers une image déjà en ligne.
3. Choisissez votre **code à 4 chiffres** et saisissez-le deux fois. C'est lui qui valide les
   offres en caisse : il est enregistré chiffré et ne s'affiche plus jamais.

Vous pouvez à tout moment **Modifier ma fiche** ou **Changer mon code** depuis votre espace.

### Créer et gérer vos offres
1. Dans votre espace, touchez **Mes offres**, puis **Nouvelle offre**.
2. Remplissez le **titre**, les **conditions** (facultatif), les **jours de validité** (ou
   **Tous les jours**), le nombre d'**utilisations par membre** et la **valeur de l'article
   offert (€)**, puis touchez **Publier l'offre** : elle apparaît aussitôt dans le catalogue.
3. Vous pouvez modifier une offre, la **Désactiver** (elle disparaît du catalogue, ses
   utilisations restent comptées) puis la **Réactiver**.

### Valider une offre en caisse
- **Avec votre code** : le membre vous tend son téléphone, tapez votre code à 4 chiffres et
  validez. « Code incorrect » : rien n'est enregistré, recommencez.
- **Avec le QR code** : dans votre espace, touchez **Scanner un QR code** et visez le QR code du
  membre. Si l'appareil photo ne marche pas, tapez le **code court** affiché sous le QR code.

Dans les deux cas, vérifiez l'écran **Offre validée** et son numéro avant d'offrir l'article.
Un QR code expiré, déjà utilisé ou destiné à un autre commerce est refusé.

### Suivre l'utilisation de vos offres
Touchez **Tableau de bord** : le nombre d'utilisations sur les 30 derniers jours, par offre et
par jour de la semaine, et les dernières validations avec leur numéro. Pratique pour choisir les
jours de vos offres.

## Questions fréquentes

**J'ai oublié mon code de commerçant.** Il ne peut pas être affiché : choisissez-en un nouveau
avec **Changer mon code**.

**Le QR code est expiré.** Il ne vaut que 5 minutes : touchez **Nouveau QR code**, ou validez
avec le code à 4 chiffres du commerçant.

**L'offre n'est pas valable aujourd'hui.** Chaque commerçant choisit ses jours : la carte et la
page de l'offre indiquent le prochain jour où elle sera valable.
